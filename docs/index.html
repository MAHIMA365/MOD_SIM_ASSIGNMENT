About this model

This browser-only discrete-event simulation represents a bus halt as an M/M/1 queue (one bay) or M/M/2 queue (two bays). Passenger arrivals form a homogeneous Poisson process; service times are independent and exponentially distributed. Passengers follow first-come, first-served discipline. With two bays, both draw from one shared waiting line. The animation shows this one stochastic run, not a measured real-world bus stop.

Inter-arrival time: −ln(U) / λ
Service time: −ln(U) / μ
Stable when: λ < cμ, where c = number of bays

How to use

  1. Choose one or two bays, set λ, per-bay μ and the observation duration.
  2. Optionally choose a seed. The same seed and parameters reproduce the same event sequence.
  3. Select Start simulation; pause and resume as needed. Reset clears the run using the current settings.
  4. Watch the queue and bays, and read the metrics as they update. The utilization denominator is the total capacity across all selected bays.
Runs entirely in your browser · No network request or backend required
